Customer Shopping Behavior Analysis
Overview

This project analyzes customer shopping behavior using 3,900 transaction records from different product categories. The goal is to understand customer spending patterns, product preferences, customer segments, subscription behavior, and purchasing trends .The project follows an end-to-end data analytics workflow from data cleaning to business insights.

Dataset
3,900 transactions
18 features
Customer demographics
Product and purchase information
Shopping and subscription behavior
Discount and shipping information

The dataset had 37 missing values in the Review Rating column, which were handled during data cleaning.

Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
MySQL
SQL
Power BI
Gamma
Jupyter Notebook


Project Steps

1. Data Loading & Cleaning:
Loaded the dataset using Python and Pandas
Checked data types and missing values
Handled missing review ratings
Renamed columns to snake_case
Removed redundant columns

2. Exploratory Data Analysis:
Analyzed customer spending patterns
Explored product and category performance
Studied customer demographics
Analyzed subscription and discount behavior
Created new features such as age groups

3. SQL Analysis:
Loaded the cleaned data into MySQL and used SQL to analyze:
Revenue by gender
Subscribers vs. non-subscribers
Top-rated products
Shipping types
Discount usage
Customer segments
Top products by category
Repeat buyers
Revenue by age group

4. Power BI Dashboard:
Created an interactive Power BI dashboard to visualize key findings and business insights.

5. Report & Presentation:
Created a business report summarizing the analysis and recommendations.Also created a presentation using Gamma to communicate the project findings.
